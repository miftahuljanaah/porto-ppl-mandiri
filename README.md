# Portofolio Seminar

Website ini merupakan portofolio digital yang disusun oleh Miftahul Janaah, mahasiswa Pendidikan Profesi Guru (PPG) Calon Guru Bidang Informatika. Website ini bertujuan untuk mendokumentasikan perjalanan, proses pembelajaran, pengalaman praktik, pengembangan kompetensi, serta refleksi diri selama mengikuti Program Pendidikan Profesi Guru. Portofolio ini menjadi media untuk menampilkan perkembangan kompetensi pedagogik, profesional, sosial, dan kepribadian sebagai calon guru yang siap menghadapi tantangan pendidikan di era digital. Melalui dokumentasi kegiatan dan hasil pembelajaran selama program PPG, diharapkan portofolio ini dapat menjadi bukti proses pengembangan diri dalam mewujudkan pendidik yang profesional, inovatif, kreatif, dan berorientasi pada kebutuhan murid.

Website ini terdiri atas beberapa menu utama, yaitu Beranda, Profil, Identifikasi Diri, Semester 1, Semester 2, Karya Inovasi, dan Refleksi. Setiap menu memuat informasi yang saling berkaitan untuk menggambarkan perjalanan belajar, pencapaian, karya, serta evaluasi diri selama mengikuti program PPG. Portofolio ini diharapkan menjadi sarana dokumentasi dan refleksi berkelanjutan dalam membangun komitmen untuk menjadi guru Informatika yang kompeten, adaptif terhadap perkembangan teknologi, mampu mengintegrasikan teknologi dalam pembelajaran, serta menanamkan nilai-nilai karakter dan etika digital kepada murid.
