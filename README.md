# Web PPL Mandiri

Website ini berisi dokumentasi kegiatan PPL Mandiri yang saya laksanakan di SMK Negeri 2 Depok. Di dalamnya terdapat berbagai pengalaman selama praktik mengajar, mulai dari persiapan pembelajaran, pelaksanaan kegiatan di kelas, kegiatan nonmengajar, hingga refleksi selama menjalani PPL. Website ini menjadi tempat untuk berbagi cerita, menyimpan hasil kegiatan, dan melihat proses belajar serta perkembangan saya sebagai calon guru Informatika
